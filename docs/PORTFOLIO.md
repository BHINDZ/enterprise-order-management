# Portfolio Project Summary

## Enterprise Order Management & API Integration Portal

A purpose-built full-stack portfolio application demonstrating modern enterprise application development.

### Business problem

Sales and service users need a single interface to create and monitor customer orders while the application communicates with an external enterprise ordering API.

### Technical approach

- ASP.NET Core Web API provides REST endpoints.
- Entity Framework Core handles relational persistence.
- SQL Server stores customers, products and orders.
- Angular provides a reusable responsive UI.
- DTOs isolate API contracts from domain models.
- Service abstractions keep business logic testable.
- External API integration is isolated behind an interface.
- Logging and centralized error handling support troubleshooting.
- Swagger/OpenAPI documents the API.

### What this demonstrates

C#, .NET, ASP.NET Core, REST APIs, JSON, SQL Server, asynchronous programming, API integration, frontend development, validation, error handling, testing, Git and CI/CD practices.
