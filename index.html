End-to-End Flow

  • User authenticates with JWT.
  • Angular submits an order.
  • ASP.NET Core validates and persists it.
  • API calls the external telecom simulator.
  • External service processes the order asynchronously.
  • Webhook callback is HMAC-SHA256 signed.
  • API validates the signature.
  • Order status is updated in SQL Server.
  • Angular detects the updated status.
